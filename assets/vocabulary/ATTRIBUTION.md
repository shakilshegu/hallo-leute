# Word data attribution

`words.json` is generated by `tool/vocab/build_vocab.py` from:

| Data | Source | License |
|---|---|---|
| Word frequency ranking | [FrequencyWords](https://github.com/hermitdave/FrequencyWords) by Hermit Dave (OpenSubtitles 2018, German) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) |
| Meanings, articles, plurals, topics | [English Wiktionary](https://en.wiktionary.org/) via [kaikki.org](https://kaikki.org/) / [wiktextract](https://github.com/tatuylonen/wiktextract) | [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) and GFDL |
| Example sentences and translations | [Tatoeba](https://tatoeba.org/) | [CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/) |

The 48 hand-picked essentials (`tool/vocab/curated.json`) were written for
Hallo Leute.

Because the inputs are CC BY-SA, `words.json` itself is shared under
**CC BY-SA 4.0**. This applies to the word data only, not to the app's code.
Credits are shown in the app on the Profile tab.
